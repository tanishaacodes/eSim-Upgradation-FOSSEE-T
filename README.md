
# eSim 2.5 Patch for Ubuntu 25.04 (Spring 2026 Internship Submission)

This repository contains a patched version of the eSim 2.5 installer specifically modified to work on **Ubuntu 25.04 (Plucky Puffin)**. 

##  How to Start
To test this installation on an Ubuntu 25.04 system, run the following commands:

```bash
# 1. Clone this forked repository
git clone -b installer https://github.com/tanishaacodes/eSim-Upgradation-FOSSEE.git
cd eSim-Upgradation-FOSSEE

# 2. Run the main installer
chmod +x install-eSim.sh
./install-eSim.sh --install

# 3. Launch eSim
esim
